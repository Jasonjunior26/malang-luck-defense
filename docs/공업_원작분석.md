# 스운디 원작 공업(공격력 업그레이드) 분석

> 대상: 스타 운빨 디펜스 v0.91 맵 + 알파고 방송 영상(26.10.10, v.webm 6625초). 표기: **확정**(맵 바이너리/화면에서 직접 확인) / **추정**(정황) / **미확인** / **해독 불가**.
> 핵심 결론: **원작 공업 비용은 영상 툴팁에서 확정됐다.** 비용 = `25 + 5 x (현재 공업 레벨)` 미네랄(기타 트랙만 5 대신 4). 최대 단계 제한은 관측상 없음(17단계까지 확인). 효과는 맵 UNIx 에서 "단계당 +기본 데미지의 100%"(저가 유닛) ~ "+1~3 고정"(고가 유닛)으로 유닛마다 크게 다름.
> 원시 자료: `raw/upg_UPGx_PUPx.txt`, `raw/up_subtitle_hits.txt`, `raw/tooltip_scan_1fps.txt`, `raw/gongup_tooltip*.png`, `raw/unit_settings.txt`(WEAPONS 절).

## 1. 확정: 공업 구매 비용 (영상 툴팁)

공업 버튼은 "공격력 업그레이드" 선택 유닛(Select 커서, 영상 21:33 `공격력 업그레이드` 선택창)을 고르면 우측 명령 패널에 **테란[Q] / 저그[W] / 프로토스[A] / 기타[S]** 4개 버튼으로 나타난다(2x3 격자). 마우스를 올리면 툴팁에 `<종족> 공업 [핫키] / 다음 업그레이드 수: N / (미네랄 아이콘) 비용` 이 뜬다. 스크래핑: 1fps 로 전체 영상 6624프레임에서 툴팁 파란 테두리 검출 후 81개 장면을 육안 판독(이미지: `raw/gongup_tooltips_a~e.png`).

### 1-2. 비용식 (확정 + 해석 추정)

| 종족 | 식 (N = 다음 업그레이드 수) | 검증 |
|---|---|---|
| 테란/저그/프로토스 | `비용 = 25 + 5 x (N-1)` | 저그 N=1,2,3,6 / 프로토스 N=1,2,4,5,6,7,8 / 테란 N=5 모두 일치 |
| 기타 | `비용 = 25 + 4 x (N-1)` | N=1,3,4,5,6,7,9,10,11,12,14,15,17 모두 일치. 왜 4 인지 **해독 불가**(UPGx 는 4개 슬롯 전부 25/5 인데 화면은 4. 트리거(EUD)로 별도 가격 처리한 것으로 추정) |

- 맵 UPGx 와 대조(**확정**, 오프셋 chk 49802, `raw/upg_UPGx_PUPx.txt`): 업그레이드 id **7(테란 보병 무기) / 10(저그 근접) / 13(프로토스 지상 무기) / 14(프로토스 공중 무기)** 만 사용자 설정(use-default=0)이고 값이 `미네랄 기본 25 + 레벨당 5, 가스 0/0, 연구시간 0/0`. 나머지 62개 업그레이드는 기본값. 즉 **영상 툴팁의 25 / +5 는 UPGx 의 25 / +5 와 정확히 일치**한다. 이 4슬롯이 테란/저그/프로토스/기타(공중 무기 슬롯 추정) 4트랙에 대응(추정). 연구시간 0 = 즉시 구매.
- **N 에는 히어로/시너지 공업이 포함되는 것으로 보인다**(추정): 가격식이 "레벨" 기반이면 아몬 시작 +N업을 받은 판의 첫 구매가 비싸야 한다. 근거: 판3(아몬, 시작 모든 공업 +4/영상) 55:23 저그 N=6 비용 50. 반대로 보너스 없는 판2 24:13 저그 N=1 비용 25. 정확한 N 정의(구매 횟수 vs 총 레벨)는 판3 초반 툴팁이 없어 완전 확정은 못 함.
- 같은 종족이라도 판마다 N 이 1부터 시작(판2 저그 N=1, 판4/5 저그 N=1) -> 비용은 **판 시작 시 25**에서 출발.

## 3. 효과: 레벨당 데미지 (맵 UNIx 확정 + 영상 1점 검증)

### 3-1. 규칙
스타 규칙: `데미지 = 기본 + 레벨 x 보너스(UNIx 의 업그레이드당 추가 데미지)`. 이 맵 WEAPONS 82종(기본 데미지>0) 분포(`raw/unit_settings.txt` WEAPONS 절, UNIx 오프셋 43300):

| 레벨당 보너스 / 기본 데미지 | 무기 수 | 해석 |
|---|---|---|
| 정확히 100% (보너스 = 기본) | **25** (+5종은 100% 초과, 예 w1 6→+12, w28 5→+15, w41 5→+10, w85 10→+20, w113 1→+3) | 레벨 1마다 +100% 기본. 레벨 N 이면 (1+N)배 |
| 10~50% | 17 | 중간 |
| 0~10% (고정 +1~3) | 27 | 고가 유닛. 업그레이드 체감 작음 |
| 0 (업그레이드 효과 없음) | 8 | 스파이더마인드(125/0), 보스급 w54(500/0) 등 |
| 중앙값 | 10% | 분위: 25% 5%, 50% 10%, 60% 14%, 75% 100% |

- **영상 검증 1점(확정)**: 우르사돈 [히든] [기타] 공격력 툴팁 "공격력: 42"(21:29, 1289초, `raw/gongup_tooltips_a.png` 3번째 칸) = WEAPONS w100 기본 42, 보너스 42(100%). 이 판 기타 N=1(공업 0)이었으므로 기본값이 일치.
- 영상 체감(확정 발언): "히드라 업그레이드 그래도 두 배 두 배... 두 배 오르니까 그나마 버티긴"(22:47) = 레벨당 +100% 기본에 해당하는 저가 유닛, "업그레이드가 진짜 크다"(41:24), "에픽이 있어도 업그레이드 잘된 거에는 못 비빈다"(47:03), "셔블링(저글링) 확실히 업그레이드가 깡패"(39:20).
- 무기 id -> 유닛 매핑은 스타 기본 weapons.dat 순서(Marine=w0, Ghost=w2 ...)로 **추정**만 가능(맵에서 변경 불가, 비표준일 수 있음). 확인된 앵커: Marine w0 = 5, +5 / 우르사돈 w100 = 42, +42. 따라서 **등급별 정확한 보너스 비율은 미확인**. 분포상 "저가 노멀 유닛은 100%/레벨, 에픽 이상은 고정 소량" 경향으로 추정.

| 효과/비용 | 저가 유닛이면 25미네랄로 유닛 종류 전체 화력 2배(레벨 1에 2배, 레벨 2에 3배 ...) | 확정(UNIx) |

원작에서 공업이 "몰빵 전략"으로 성립한 이유(추정): 단계당 비용이 아주 싸고(뽑기 1.7~5회분) 효과는 100%/레벨(가산)이라 레벨 10 까지 누적 475로 **같은 종족 유닛 전체 화력 10배**를 얻는다.

## 7. 우리 설계(4무리 공업 트랙) 권장값

현재 설계 J3: `비용 60+10b, 25단계, +12%/레벨(가산)`. 원작 대비 **비용은 비싸고 효과는 약해** 공업의 존재감이 원작(후반 몰빵 가치)에 못 미친다. 권장:

### 7-1. 비용 곡선 (원작 그대로 이식 가능 — 우리 뽑기도 15)
| 항목 | 권장 | 근거/상태 |
|---|---|---|
| 비용 | `cost(Lv) = 25 + 5 x Lv` (Lv = 현재 표시 레벨, 히어로/시너지 보너스 포함) | 원작 확정. 뽑기 15 가 같아 변환 불필요 |
| 무리별 독립 | 4무리 각각 독립 가격 | 확정 |
| 별빛(기타) | `25 + 4 x Lv` (선택 사항: 소수 무리 우대) 또는 4무리 통일 5 | 확정(원작), 통일도 무방 |
| 최대 레벨 | 원작은 상한 없음(17+ 확인). 모바일은 **상한 25 유지 권장**(UI 단순), 이후 비용 +5 는 계속 | 우리 신규 |
| 보너스 레벨 가격 | 원작처럼 보너스도 비용 기준 레벨에 포함(비싸짐) 또는 별도 구분. **추천: 포함**(히어로 +3 이 가치 있으면서 과열 방지) | 추정 |

### 7-2. 효과
| 안 | 단계당 효과 | 장단점 |
|---|---|---|
| A. 원작 충실 | 커먼~노멀: 기본의 +100%/레벨(가산), 레어: +50%, 유니크: +25%, 히든 +12%, 에픽 +8%, 레전더리 이상 +6%, 패런츠 +10% | 원작 분포(고가 유닛 +고정 소량)를 등급 비율로 근사. 등급별 값은 **추정**(UNIx 앵커: Marine/우르사돈만 직접 검증) |
| B. 통일 (구현 간단) | 모든 유닛 **+35%/레벨 가산** (`x(1+0.35 Lv)`), Lv10 = x4.5 | 원작 하위유닛 효과(Lv10 = x11)보다 낮지만 고가 유닛(Lv10 약 x1.1~1.3)보다 강해 공업 몰빵이 의미 있음. **권장 기본값** |
| C. 현행 | +12%/레벨 | 원작 대비 약함, 효과/비용 0.2 로 공업이 합성보다 항상 열세 가능 |

가산(레벨 N -> 1+k N) 방식이 원작과 같으며 곱연산(1.x^N)은 후반 폭주 위험이 커서 비권장.

변환식(근거): 원작 "레벨당 기본 데미지의 100%" 는 레벨 10에서 11배. 우리 몹 HP 곡선(A7)이 원작 표 기반이므로 단순 이식하면 공업 몰빵 한 종족이 라운드 25~40 몹을 증발시켜 난이도가 붕괴한다. 따라서 효과를 원작의 35%(안 B)로 줄이되, 비용을 원작과 같은 25+5Lv 로 낮춰 "싼 값에 완만한 성장"으로 조정. 시뮬(`이식설계_밸런스시뮬.js`) 의 up 정책 계수를 `0.12 -> 0.35`, `cost = 60+10b -> 25+5Lv` 로 바꿔 검증하고, 목표 지표 3개: (1) 한 무리 화력 비중 40% 이상일 때 공업이 합성(3기->상위 등급)보다 효율 우위, (2) 50라운드 클리어 시 총 공업 구매 비용이 누적 수입의 25~40%(원작 판5 정황: 후반 대부분 몰빵), (3) 보너스 레벨 없이 무리 하나를 25까지 올리는 총 비용 2,125 이 라운드 40 이전 수입으로 도달 불가.

### 7-3. 경제 비율 이식
| 원작 비율 | 우리 값 |
|---|---|
| 공업1/뽑기 = 1.67 | 뽑기 15 -> 공업1 25 (그대로) |
| 단계 증가 = 뽑기의 1/3 | +5 (그대로) |
| 보스 +50 | 공업 2회분(N=1,2: 55)에 근접 -> 보스 보상은 그대로 +50. 우리는 보스 보상으로 **무료 공업 1단계(선택권)** 를 추가하므로 보스 공업 선택권은 **레벨 5 이하 구간에서만 지급**하거나 보너스 구간 상한(보너스+구매 <= 12)을 두어 과열 방지 |
| 시작금 50 | 그대로(공업 2회 가능, 초반 선택지 제공) |
| 몹 처치 +2 | 그대로. 공업 단계당 약 12~35 처치분 = 라운드 1~2회분 수입 |
