## 재개 절차 (새 세션 첫 일)
1. `git status`, `git log --oneline -3` 로 WIP 커밋 확인. `docs/디자인_구현_1.md` 가 있으면 읽고 미완 항목 확인.
2. 검증: `node tools/build_engine.js` → `tools/test_*.mjs`, `tools/check_globals.mjs` 실행, `node --check sw.js ui.js game.js`. engine.js 가 game.js 와 일치하는지 확인.
3. 로컬 서버(`python -m http.server`)로 Chrome 확인: 라이트 외형이 기존과 동일한지, 다크(OS 설정 또는 DevTools 에뮬레이션)에서 HUD·카드·모달·메뉴·하단 바가 읽히는지, 폰트가 Pretendard 인지(캔버스 배너·데미지 숫자 포함).
4. 문제가 없으면 §9 의 3단계로 진행.
