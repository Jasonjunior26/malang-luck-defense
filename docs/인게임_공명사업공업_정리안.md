## 0. 사용자에게 확인할 질문 (추천안 포함)
1. **"사업"이 뭘 가리키나요?** 코드·UI 어디에도 "사업/biz/투자/광산"은 없음(사업자 등록 얘기뿐). 이 문서는 **사업 = 사거리 강화(🎯)** 로 가정함. 다른 것이면 알려주세요. (추천: 가정 유지)
2. **줄 단추 구성**: (A) 줄에 `공업`·`사거리` 단추 둘 다 두되 간격·터치 영역 분리 / (B) 줄에는 `공업`만, 사거리는 줄 탭 말풍선으로 이동. **추천 A**(자주 쓰는 액션은 한 번에, 오탭은 간격으로 해결). 줄이 너무 답답하면 B.
3. **알림 등급**: 공명 발동/해제를 지금(중앙 배너)에서 원칙 §7대로 **L(좌하단 로그)** 로 내릴까요? 추천: 발동은 로그+줄 반짝임, **해제만** 중앙 M(손해라서). 첫 발동 +💎50 은 로그 한 줄로 통합.
4. **무리 줄 높이**: 지금 32px 줄 4개(터치 영역이 줄끼리 겹침). 44px 로 키우면 +약 50px 세로가 필요(보드·정보 패널이 줄어듦). 추천: 줄 40px + 단추 44px 터치(줄 사이 간격 4px)로 절충, 작은 화면(높이 700 이하)은 현행 유지.

## 3. 정리안 (규칙 수치 불변)
**용어 3개 고정**: `공업`(무리 Lv 올리기, 💎) / `공명`(자동 보너스, 다른 등급 모으기) / `사거리`(무리 사거리 +8%, 💎). "사업/강화" 표기는 쓰지 않음.

**줄 와이어프레임(추천 A, 줄 40px)**
```
 평상시  [🐸 Lv27 ✦+2]  [■][■][■][■]  [ 공업 ⬆25 ][ 사거리 20 ]
 공명중  줄 배경 살짝 밝게 + Lv 옆 ✦+2(금색/초록, 빨강 폐기)
 한 칸전 [■][■][■][?]   ← ? 만 펄스 3회(8회→3회), 로그 "1종 남음" 삭제
 공업권  [ 공업 ⬆🎫1 ]  ← 탭 시 말풍선(무료/💎)
 부족    칩 흐리게(글자 유지) / MAX 는 "공업 MAX"
```
- 단추: 공업 = Secondary 금색 채움 + 동사형 "공업 ⬆", 사거리 = 파랑 아웃라인. 터치 44px 는 **칩끼리 겹치지 않게** `::after` 를 가로 0, 세로만 확장(줄 40 + 간격 4 = 44 피치), 칩 사이 간격 8px.
- 비용 숫자는 14px(`--fs-body`), 라벨은 12px 허용. `+단계` 뱃지 유지.
- 상태 `공명`: 글자 `✦+2`(Lv 줄 안), 설명은 줄 탭 말풍선에서만.
