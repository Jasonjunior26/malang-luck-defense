# 랭킹 화면 재설계 (2026-11-08, sw v28-rank-ui)

**문제**: 랭킹 모달이 제목 + 리그 탭 + 보조 탭 + 시즌 ◀▶ + 기간 문구 + 인원 문구까지 위에만 5~6줄을 차지했고, 줄마다 점수·R·히어로·빌드·승점 안내가 2~3줄로 붙어 목록이 한 화면에 4~5명만 보였다. 시즌 기간·승점 규칙은 위(rksub)와 게임 종료 화면에서 중복되고, 순위 변동/다음 순위/1위까지/최고 기록이 판 종료 칸에 5줄로 나열됐다. 모달 전체가 스크롤돼 탭과 내 순위가 같이 밀렸다.
**변경**: (1) 상단은 2줄만: 1줄 = 운빨 리그|내 영웅 리그|내 기록, 2줄 = 시즌 ◀▶ + [순위|승점] 소형 토글(내 기록 탭은 1줄뿐). 제목 "랭킹"·기간·인원 문구 제거. (2) 목록 줄은 핵심 3칸(순위·이름+작은 R·점수) 한 줄, 영웅·빌드·승점은 줄을 눌러 펼침(.xt). (3) 모달을 높이 min(92dvh,680px)·폭 440px 로 키우고 목록(.rkl)만 스크롤, 하단은 고정: 내 순위 한 줄(이름 옆 "다음 +N"), 메타 한 줄(기간·남은 일·인원·hh:mm 기준 ↻), 버튼(다시 하기|홈으로는 한 줄). (4) 판 종료 칸(rankResultHtml)은 큰 줄 1 + 작은 줄 1(점수 변화 · 다음 순위까지). 캐시·호출·준비 중·다시 시도·내 순위 하이라이트와 서버/캐시 키 로직은 그대로.
