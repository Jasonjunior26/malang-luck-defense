## 핵심 경로
- 시작: init -> restart -> newGame(시드) -> loop
- 프레임: loop -> update(startWave/spawn, 슬롯 쿨다운 -> launch -> 투사체 -> impact -> hitMob/splash, 몹 이동, 패배 판정) -> render(drawBoard, drawChar, drawMob, drawProj, drawEfx, drawPart)
- 뽑기: 버튼 -> draw -> pickTier(시드 RNG) -> 슬롯 배치 / 합성: tapSlot -> 동일 3기 -> 상위
- 종료: update -> gameOver(ui.js) -> ranking(Supabase)

## [난수/난이도 개편 갱신]
- 시드: newGame(mode, forceSeed) 가 매 판 Math.random 시드를 뽑음(daily 고정 시드 폐지). 서버 index.ts 는 1~2147483646 정수 시드만 검사하고 그 시드로 재생. "오늘" 랭킹은 played_at >= KST 자정 + 이름별 최고 1건(ui.js kstMidnightISO, fetchRanks).
- 속도 x1.5: 일반 라운드 speed 60->90, gap/1.5, n x1.5, 개체 HP·rew 는 총량 유지 비율로 재계산. 보스는 한 바퀴를 시간의 70%에 도는 속도 + 제한시간 +15s(r50 은 75s). HP_MUL 1.5->4(봇 시뮬 중앙 r45~50, 완주 0%). SCORE.KILL_MUL 0.667 (몹 수가 1.5배라 점수 보정). GAME_VER 3.
- 로그: 레어 미만 뽑기/합성 메시지 숨김(game.js draw·merge). HUD: 점수 칩(hScore) + 남은 시간(hCh) 추가.
