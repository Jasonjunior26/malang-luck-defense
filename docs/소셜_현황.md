## (c) 로그인 없이 가능 vs 로그인 필요
로그인 없이(현재 라이브): 게스트 플레이(기기 device_id), 닉네임 랭킹, 주간 시즌 랭킹·누적 승점, 내 영웅/코인 마켓, 랭킹 도전(구 일일 챌린지), 시즌 규칙 엔진(`rules`, 서버 검증·재생).
로그인(JWT) 필요: 프라이빗 시즌 전 기능(만들기/참가/제출/순위), 친구 전 기능, 기기 기록→계정 연결(003 `link`), 초대 링크 수락, 공식 시즌 랭킹도 로그인 필수로 확정했으나 **현재 공식(주간) 시즌이 로그인 없이 도는 것으로 보임 — 기획 확정사항과 실제 구현의 차이 여부 미확인**(진행현황은 주간 시즌을 게스트 랭킹으로 서술).
로그인 불필요하지만 막힌 것: 카톡 카드 공유(카카오 앱 등록 필요, 로그인 아님).
로그인 켜지는 즉시 마이그레이션·함수 추가 배포 없이 사용 가능(플래그 true + `sw.js` CACHE_VERSION 올림 + push) [문서]. 단 구글 추가는 `auth.js` 수정이 필요.
