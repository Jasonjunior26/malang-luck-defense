# 말랑 디펜스 소셜화 설계안

2026-10-30. 지인 수십 명으로 시작, 공개 서비스로 확장 가능한 구조.
기반: Supabase(Edge Function `submit-score` 가 입력 로그를 재생해 점수 검증), 기기 ID 닉네임, 하드코딩 `SEASONS`, 히어로 10종.

## 원칙
- 시드는 항상 랜덤 (운빨 디펜스). 시즌 옵션에 없음.
- 시즌 규칙(`rules`)은 엔진 입력. 서버가 DB 의 규칙으로 재생해 검증한다. 클라가 보낸 규칙은 불신.
- 게스트로 바로 플레이, 랭킹·친구·시즌 참가 때만 카카오 로그인.
- 규칙은 화이트리스트 키 + 수치 범위만 허용. 엔진이 바뀌면 GAME_VER 증가.

## 1. 로그인 (카카오)
- Supabase Auth Kakao OAuth, 동의항목은 닉네임/프로필만.
- 첫 로그인 시 기기 기록을 계정에 연결 (`players.user_id`). 기존 이전 코드는 유지.

## 2. 친구
- 닉네임#코드 또는 초대 링크(`?friend=코드`). 전화번호 수집 없음.
- `friendships(a, b, status)`. 요청→수락, 차단, 레이트 리밋.
- 친구 목록 + 랭킹의 "친구" 탭.

## 3. 카카오톡 공유
- Kakao JS SDK 피드 카드: 점수·라운드·순위 + "나도 도전" 초대 링크.
- 필요: 카카오 앱에 도메인 등록.
- 공유 위치: 게임오버, 시즌 랭킹, 시즌 초대. 보조로 Web Share(인스타 포함), 링크 복사.

## 4. 프라이빗 시즌
- 생성: 이름 → 기간 → 규칙(프리셋/모디파이어) → 초대 링크·코드.
- `private_seasons(id, owner, name, start_date, end_date, rules jsonb, invite_code, max_players)`, `season_members`, `scores.season_id`.
- 제출: `submit_score_private` — 서버가 시즌 규칙으로 재생, 기간·멤버십 검사.
- 제한: 계정당 진행 시즌 3개, 기간 최대 60일, 이름 필터.
- 종료 시 순위 확정, 우승 칩, 카톡 공유.

## 5. 시즌 모디파이어
`rules = { rounds, mods: [{k, v}] }`, 최대 3개 조합.

| 분류 | 키 | 효과 |
|---|---|---|
| 난이도 | `hpMul` | 몹 체력 ×0.7~2.5 |
| | `mobSpeed` | 몹 속도 ×0.8~1.5 |
| | `mobCount` | 몹 수 ×0.8~1.6 |
| | `bossTime` | 보스 제한시간 -10~+15초 |
| 제약 | `noGrade` | 커먼(또는 커먼+노멀) 제외, 확률은 윗등급에 재분배 |
| | `gradeCap` | 합성 최대 등급 |
| | `drawLimit` | 총 뽑기 횟수 제한 |
| | `noSell` | 판매 금지 |
| | `clanBan` | 특정 무리 제외 |
| | `heroPool` | 히어로 제한/고정 |
| 자원 | `startMin` | 시작 미네랄 0~200 |
| | `killReward` | 처치 보상 ×0.5~2 |
| | `drawCost` | 뽑기 비용 10~25 |
| 확률 | `luckyWeek` | 상위 등급 확률 2배 |
| 확장 | `rounds` | 50 → 70 / 100 / 엔드리스 |

**라운드 확장:** 50라운드 이후 HP 곡선을 연장하고 10라운드마다 보스. 엔드리스는 도달 라운드가 순위 기준. 서버 재생 시간 때문에 상한은 측정 후 확정.

**프리셋**
- 맨몸 서바이벌: 커먼 제외 + 시작 미네랄 0 + 판매 금지
- 하드코어: 체력 ×1.8 + 속도 ×1.2 + 보스 시간 -5초
- 운빨 파티: 상위 등급 확률 2배 + 뽑기 비용 20 + 처치 보상 ×1.5
- 마라톤: 100라운드 + 체력 ×0.9
- 한 우물: 무리 1개만 사용 + 히어로 고정
- 엔드리스: 라운드 무제한

시즌 규칙은 화면 상단 칩으로 항상 표시. 시즌 간 점수 비교는 하지 않음.

## 6. 히어로 신규 10종 (총 20종)
기존 `fx` 훅을 재사용하거나 훅 1개 추가 수준만 포함. 확률은 합 100으로 재정규화.

| # | 이름 | 효과 |
|---|---|---|
| 1 | 대장장이 두루미 | 강화 비용 -15% |
| 2 | 에누리 오리 | 판매가 +50% |
| 3 | 반딧 요정 | 뽑기 비용 -2 |
| 4 | 복리 햄스터 | 라운드 시작 시 보유 미네랄 100당 +2 (최대 +20) |
| 5 | 느릿 거북 | 몹 이동 속도 -10% |
| 6 | 사냥꾼 매 | 보스 피해 +20% |
| 7 | 쌍둥이 다람쥐 | 합성 시 8% 확률로 결과 1기 추가 |
| 8 | 서리 여우 | 공격 둔화 확률 +15% |
| 9 | 불씨 도깨비 | 보스 제한시간 +10초, 화상 지속 +30% |
| 10 | 합성 장인 두더쥐 | 합성 성공 시 미네랄 +3 |

제외(구현 부담): 복수의 늑대(몹 위치 판정), 선택권 곰돌이(선택 UI 변경), 룰렛 두꺼비(선택권 큐 추가). 필요하면 후속으로.

그래픽은 `docs/캐릭터_생성가이드.md` 규칙대로 부품 조합으로 생성. 밸런스는 봇 시뮬로 히어로별 도달 라운드가 기존 ±8% 안인지 확인.

## 7. UX 정리 (선행)
- "3개 모이면 합쳐짐", "다음 유닛" 등 상시 안내 제거. 첫 판 한정 토스트 1회로 대체.
- 타이틀: [시작] [시즌] [친구] [랭킹].

## 8. 보안
- RLS: 시즌은 멤버만 조회, 호스트만 수정(시작 후 규칙 변경 불가). 규칙은 서버에서 스키마 검증.
- `rules_hash` 를 점수와 함께 저장. 시즌 생성·가입·친구 요청·제출에 레이트 리밋.
- 카카오에서는 닉네임만 저장.
