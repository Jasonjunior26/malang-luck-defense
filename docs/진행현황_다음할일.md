## 2. 분기: 소셜 로그인 없이 되는 것 vs 로그인이 필요한 것
**로그인 없이 지금 동작 (완료·배포됨)**
- 히어로 20종(신규 10종), 매 판 랜덤 시드(히어로·뽑기 모두), 공명 가시화, 전체화면/PWA 보정, UX 정리, HUD 칩 넘침 수정
- 버튼 이름 "랭킹 도전"(구 일일 챌린지), 시즌 엔진 `rules`(모디파이어 15종, 라운드 50~200)
- 기존 닉네임 랭킹, 시즌 랭킹, 연습 모드

**로그인(JWT)이 있어야 동작 — 코드·서버는 완성, 로그인이 막혀서 실사용 불가**
- 프라이빗 시즌 만들기/참가/제출/순위 (`seasons.js`, 서버 `private.ts`, 004)
- 친구 요청/수락/차단/친구 랭킹 (서버 `friends.ts`, 005 — **클라이언트 친구 화면은 아직 없음**)
- 기기 기록 → 계정 연결 (`auth.js`, 003)
- 초대 링크 `?join=코드` 수락 (로그인 후 이어짐)
- 카톡 카드 공유 (아직 미구현, Web Share/링크 복사만 있음 → `seasons.js` 의 `shareInvite(season)` 한 곳에 SDK 를 끼우면 됨)

**소셜 로그인 현재 상태**
- `config.js` `KAKAO_ENABLED:false` → 로그인 버튼은 "준비 중". 시즌/친구 기능이 모두 이 플래그에 막혀 있다.
- 카카오: 개발자 앱 등록 시 사업자 정보를 요구받음(2026-10-30 사용자 확인). 닉네임/프로필만으로 비즈 앱 없이 되는지 **미확인**. 어느 단계에서 요구하는지 확인 필요. 설정 절차는 `카카오_로그인_설정.md`.
- 대안(권장 후보): **구글 로그인** — Supabase 기본 지원, 사업자 등록 불필요. 계정 연결 구조(003, `auth.js`)는 제공자와 무관하므로 `auth.js` 에 provider 인자 + 버튼만 추가하면 됨. 구글 클라우드 콘솔에서 OAuth 클라이언트 생성 + Supabase Providers > Google 입력 필요(사용자 작업).
- 소셜 로그인이 켜지면 그 즉시 시즌/친구 서버 기능을 쓸 수 있다(추가 마이그레이션·배포 불필요). 켜는 법: `config.js` 플래그 true + `sw.js` CACHE_VERSION 올림 + push.

## 5. 운영 메모
- 서버 배포는 **커밋된 상태만** 임시 worktree 로 떠서 실행(작업 중 파일이 섞이지 않게): `git worktree add --detach <경로> HEAD` → `supabase/.temp` 복사 → `supabase db query --linked -f <sql>` / `supabase functions deploy submit-score --no-verify-jwt` → worktree 제거.
- 마이그레이션 적용 후 CLI 의 migration list 에는 원격 기록이 비어 보임(SQL 을 직접 실행했기 때문, 정상).
- 엔진/데이터를 바꾸면 `node tools/build_engine.js` 로 `engine.js` 재생성 + `GAME_VER` 증가 + 서버 재배포.
- 테스트: `node tools/test_{replay,function,private,rules,friends,seasons_ui}.mjs` — 모두 통과 상태(14/60/65/107/54/80).
- 화면 변경 후 `sw.js` CACHE_VERSION 올릴 것(현재 `v8-private-seasons`). 로컬 주소는 브라우저 도구로 열리지 않음 → 배포본으로 확인.
- 푸시: 작업 브랜치에서 `git push origin HEAD:main` (Pages 는 `main` 루트).
