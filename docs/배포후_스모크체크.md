# 배포 후 스모크 체크 (claude-in-chrome)

대상: 배포 URL https://jasonjunior26.github.io/malang-luck-defense/ (캐시 회피: 끝에 `?v=타임스탬프`).
절차: `navigate` -> 창 크기 390x844(`resize_window`) -> 아래 스니펫을 `javascript_tool`에 순서대로 붙여넣는다. 각 결과가 모두 `ok:true`여야 통과.
전역: `S`(game.js `let S`), `TITLE_ON`, `MODAL_ON`, `CONFIRM_ON`(ui.js). `let` 전역이므로 `window.S`가 아니라 `S`로 접근한다.
버튼 id: `start`, `rank`, `home`, `cno`, `cok`, `modal`, `confirm`. 칩 id: `cWave`, `cScore`, `cMin`, `cMob`. (index.html에서 확인한 id. 바뀌면 이 문서도 갱신)

## 0. 로드 확인
```js
({ok: typeof S!=="undefined" && typeof TITLE_ON!=="undefined", title: TITLE_ON, ids: ["start","rank","home","cWave","cScore","cMin","cMob"].filter(i=>!document.getElementById(i))})
```
기대: ok:true, ids:[] (없는 id가 없음).

## 1. 타이틀에서 [랭킹]이 게임을 시작하지 않는가
```js
(async()=>{const w=ms=>new Promise(r=>setTimeout(r,ms));
document.getElementById("rank").click(); await w(800);
const r={titleOn:TITLE_ON, modalOpen:document.getElementById("modal").classList.contains("on"), tick:S.tick, over:S.over};
document.getElementById("modal").click(); await w(300); return {...r, ok: r.titleOn===true}})()
```
기대: titleOn:true (랭킹을 열어도 게임이 시작되지 않음). 닫는 방법이 다르면(닫기 버튼) 수동으로 닫는다.

## 2. 시작 후 몬스터 등장과 틱 진행
```js
(async()=>{const w=ms=>new Promise(r=>setTimeout(r,ms));
document.getElementById("start").click(); await w(300);
const t0=S.tick; await w(3000);
const mon=(S.mobs||S.mons||S.enemies||[]).length;
return {tick0:t0, tick1:S.tick, paused:S.paused, mon, round:S.round, ok:S.tick>t0 && !S.paused}})()
```
기대: tick 증가, paused:false. 몬스터 배열 이름이 다르면 `Object.keys(S)`로 확인해 mon을 교체. mon 값은 참고용이고 통과 판정은 tick 증가와 paused:false.

## 3. HUD 칩 높이와 넘침
```js
(()=>{const ids=["cWave","cScore","cMin","cMob"];
const rs=ids.map(i=>{const e=document.getElementById(i),r=e.getBoundingClientRect();
const over=[...e.querySelectorAll("b,small")].filter(c=>c.scrollWidth>c.clientWidth+1).map(c=>c.id||c.tagName);
return {id:i,h:Math.round(r.height*10)/10,w:Math.round(r.width),over}});
const hs=rs.map(r=>r.h);
return {rs, ok:Math.max(...hs)-Math.min(...hs)<=1 && rs.every(r=>!r.over.length)}})()
```
기대: 높이 차 1px 이하, 넘침 없음. 큰 숫자 검증: 콘솔에서 `document.getElementById("hMob").textContent="999/999"` 후 재실행(통과하면 새로고침으로 복원).

## 4. 모달 열기/닫기 후 정상 진행 (게임 중)
```js
(async()=>{const w=ms=>new Promise(r=>setTimeout(r,ms));
document.getElementById("rank").click(); await w(600);
const during={paused:S.paused, modal:MODAL_ON};
document.getElementById("modal").click(); await w(400); // 배경 클릭 닫기. 안 닫히면 닫기 버튼으로
if(MODAL_ON) (document.querySelector("#box button")||{click(){}}).click();
await w(400); const t0=S.tick; await w(2000);
return {during, after:{paused:S.paused, modal:MODAL_ON, adv:S.tick-t0}, ok:during.paused===true && !MODAL_ON && S.tick>t0}})()
```
기대: 모달 중 paused:true, 닫은 뒤 modal:false 이고 tick 증가.

## 5. 홈 확인 모달: 취소와 확인이 서로 다르게 동작하는가
```js
(async()=>{const w=ms=>new Promise(r=>setTimeout(r,ms));
const home=document.getElementById("home"), cf=document.getElementById("confirm");
home.click(); await w(400); const opened=cf.classList.contains("on");
document.getElementById("cno").click(); await w(400);
const afterNo={confirm:cf.classList.contains("on"), title:TITLE_ON, paused:S.paused}; // 기대: 닫힘, 타이틀 아님, 진행 재개
const t0=S.tick; await w(1500); const adv=S.tick-t0;
home.click(); await w(400);
document.getElementById("cok").click(); await w(600);
const afterOk={title:TITLE_ON};                                                   // 기대: 타이틀로 이동
return {opened, afterNo, adv, afterOk, ok:opened && !afterNo.confirm && !afterNo.title && adv>0 && afterOk.title===true}})()
```
기대: 취소는 게임 유지와 재개, 확인은 타이틀 이동. 하나라도 어긋나면 #7 재발.

## 사용 규칙
- 결과 JSON 전체를 배포 보고에 붙인다(스크린샷 1장은 선택). 실패 시 배포 보류.
- 이 스니펫은 `ui.js` 구조(전역 이름, 모달 닫기 방식) 가정에 의존한다. 코드 변경 시 가장 먼저 깨지는 곳이 여기이므로 변경한 에이전트가 갱신한다. 미실행 상태이므로 처음 실행할 때 id와 배열 이름을 한 번 보정해야 할 수 있다.
