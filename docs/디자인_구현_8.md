# 디자인 구현 8: 인게임 알림 3등급 (design/v1, 미커밋)
등급(원칙 §7): 크기는 토큰 3개만 `--fs-alert-l 14 / -m 26(=--fs-num) / -s 34`. 배너 Jua+외곽선 2px+짧은 그림자(`--ban-stroke/--ban-shadow`), 로그 Pretendard.
| 등급 | 위치·연출 | 길이 |
|---|---|---|
| S | 중앙(top 34%), 34px, 확대 팝+화면 플래시(+기존 sfx) | 2.4s |
| M | 중앙, 26px, 작은 팝(플래시 없음) | 1.8s |
| L | 좌하단 로그, 14px, 어두운 캡슐+흰 글씨+왼쪽 색 점, 최대 3줄, 같은 문구 ×N, 4초 후 페이드 | 4s |
- 배너 큐: 같은 등급 FIFO(간격 0.3s), 대기 최대 3, 넘치면 낮은 순(info/warn류 < epic·boss < S)에서 오래된 것부터 버림, S 는 M 을 끊고 선점·큐에서 M 앞. 연출은 transform/opacity 만, reduced-motion 은 페이드만(`banFade`).
- kind→등급(`KIND_GRADE`, 모르는 kind=M): S=legend·parents·win·big / M=epic·boss·warn·round·hero·info / L=hi·tip(uiBanner 가 로그로 보냄). "big"(game.js)은 정의 없던 값 → 제거하고 legend/parents 로 통일.
- 새 알림: 전설·승리급이면 `uiBanner(문구,"legend")`, 놓치면 안 되는 상태 변화면 M kind, 나머지는 `log()`/`uiLog()`(22자 이내 해요체).
