# 밸런스: 적 밀도 · 속도감 (피드백 "적이 적어 빈 구간 / 속도감 낮음")

## 요약 (체감)
몹 지름 24px(반경 12), 트랙 둘레 1328px 기준. 일반 라운드 대표 4개(보스 라운드 5의 배수는 별도: 1기, 속도 14→20).

| 라운드 | 몹 수 전→후 | 몹 간격 전→후 | 한 라운드 몹 열 길이/트랙(1328) 전→후 | 트랙 1바퀴 통과 전→후 |
|---|---|---|---|---|
| 1 | 12 → 32 | 51px → 36px | 606px(46%) → 1152px(87%) | 35s → 22s |
| 9 | 15 → 33 | 41px → 35px | 610px → 1148px | 35s → 22s |
| 24 | 20 → 35 | 30px → 33px | 608px → 1155px | 35s → 22s |
| 49 | 28 → 39 | 22px(겹침) → 30px | 606px → 1170px | 35s → 22s |
| 보스(5,10..) | 1기 | - | - | 95s → 66s (속도 14→20) |

"트랙 위 평균 몹 수"(미처치 시 한 라운드 분량): r1 12→32, r9 15→33, r24 20→35, r49 28→39. 실제 평균은 처치율에 따라 낮아지지만 같은 비율로 증가.

## 진단 (전)
- 스폰 구간 16s(SPAWN 0.8) x 속도 38px/s = 열 길이 약 606px. 라운드 20s 중 마지막 4s 는 무스폰, 둘레 1328px 의 54% 는 항상 빈 구간(초반 r1 은 몹 간격 51px = 지름 2.1배라 듬성듬성, 초반 처치가 빠르면 트랙이 텅 빔).
- 후반(r40+)은 gap 0.57s x 38 = 22px 로 오히려 겹침. 즉 초반 듬성/후반 뭉침의 불균형.
- 38px/s 는 1바퀴 35초라 느린 인상.

## 수정
- 속도: 일반 38→60(x1.58), 번개박쥐 65→102, 큰 알 27→42, 보스 14→20.
- 스폰: gap 0.60s(r1) → 0.50s(r49) 선형, 스폰 구간 = 라운드 전체(마릿수 N = floor(19.6/gap)). 라운드 사이 빈 틈 없음. 간격 30~36px(지름 1.25~1.5배).
- 총 HP 유지: 개체 HP = 구 HP x 구N / 신N (예 r1 28→11, r49 18150→13031). 총량 변화 <1%.
- 보상 유지: ROUNDS 12번째 열 rew = 구N/신N. 처치 보상 = KILL_REWARD x rew (소수는 S.rewAcc 에 누적 후 정수 지급). 보스 보상 불변.
- 패배/경고 임계: MOB_LOSE 100→160, 경고 80/90→130/145 (구 100기 = 약 5라운드 분량 -> 신 약 4.5~5라운드 분량, 개체 HP 가 낮아 처치 효율도 감안). ui/HUD 는 CONST 를 읽어 자동 반영.
- 성능: nearest 가 몹별 trackPoint 재계산 대신 이동 루프에서 갱신한 m.pt 캐시 사용.
- 보스: 1기 + 시간제한 유지(호위 없음, 기존과 동일).

## 검증
- smokeAll(12분 시뮬 상당): 16~18s -> 16s (kills 599 -> 1159, 실행시간 증가 없음).
- 봇 17판(smokeBal), 중앙값/최소/완주. 난수 시드가 매번 달라 완주 수는 ±2 흔들림.

| HP_MUL | 중앙 라운드 | 최소 | 완주 |
|---|---|---|---|
| 1.0 | 50 | 50 | 7/17 (41%) |
| 1.25 | 50 | 40 | 4/17 |
| 1.5 (채택) | 50 | 35~50 | 2~4/17 (12~24%, 5회 반복) |
| 1.75 | 50 | 40 | 2/17 |
| 2.0 | 45 | 5 | 0/17 |

전 기준 HP_MUL=1.5 에서 완주 약 18% -> 후 약 12~24%로 동일 구간, 조기 패배 없음. HP_MUL 은 1.5 유지.
