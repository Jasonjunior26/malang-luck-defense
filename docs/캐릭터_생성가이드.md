# 캐릭터 이미지 넣는 법

`assets/sprites/<종족>.png` 파일을 넣으면 해당 캐릭터가 벡터 그림 대신 이미지로 자동 교체된다. 없는 종족은 기존 벡터 그림이 그대로 나온다. 코드 수정 불필요.

## 규격
- PNG, **투명 배경**, 정사각형 512x512 (최소 256)
- 정면, 전신, 캐릭터가 캔버스의 약 80%를 채우고 발이 아래쪽 중앙
- 그림자·바닥·글자 없음 (게임이 그림자를 따로 그림)
- 왕관은 넣지 말 것 (히어로에게는 게임이 따로 씌움)

## 파일명 (13종)
chick hamster frog / cat bunny dog / fox panda koala / unicorn dragon lion / bear
(bear는 히어로 전용)

## 생성 프롬프트 템플릿 (이미지 생성 AI용)
> cute chibi {animal} character, kakao friends style, round soft body, tiny dot eyes with white highlight, pink blush cheeks, simple thick-ish outline in darker tone of body color, flat pastel colors with soft shading, front view, full body, centered, transparent background, no shadow, no text, game sprite, 1:1

- 스타일을 13종 모두 같게 하려면 첫 결과물을 참조 이미지로 계속 넣을 것
- 등급별 변형(예: 전설은 오라)은 게임이 입히므로 이미지에는 불필요
- 배경 제거는 remove.bg 등으로 처리

## 확인
`index.html`을 새로고침하면 바로 반영된다 (파일 서버로 열어야 이미지가 로드됨: `python -m http.server`).
