# 스타 운빨 디펜스 v0.91 맵 분석

> 분석 대상: `스타 운빨 디펜스 v0.91.scx` (제작자 패런츠TV). 바이너리로만 읽음(실행 안 함).
> 확신도: **[확정]** = 맵 데이터에 명시, **[추정]** = 간접 근거, **[미해독]** = 해독 못함.

## 0. 진행 상황 / 남은 일 (중요)

**인페스티드 듀란** 히어로가 있으면 커먼/노멀 확률이 서로 바뀜(커먼 30% / 노멀 45%) — 당첨 메시지 "30%의 [커먼]", "45%의 [노멀]" 존재.

## 5. 웨이브

### 5.1 구조 [확정/추정]
- 총 **50라운드**, 10챕터 x 5라운드. **5의 배수 라운드는 보스(건물 유닛)**. 라운드 번호는 P5의 Deaths(u197) 변수 [확정].
- 라운드마다 해당 몬스터 1종이 여러 스폰 지점(location 15/23/31/39 계열, 또는 68/70/72/74 계열)에서 생성됨. 생성 트리거는 `CreateUnitWithProperties(P6, 몬스터, x1, 지점)` 형태 [확정]. **라운드당 총 마리수·스폰 간격은 미해독**.
- 일반 라운드: 새 라운드 시작 시 "새로운 라운드가 시작되었습니다!" 방송 + 히어로 라운드 수입 지급.
- 보스 라운드: "보스가 등장했습니다! 제한시간 내에 보스를 잡지 못하면 패배합니다!", 카운트다운 타이머 시작(보스가 보스 지점 loc5에 살아있는 채 카운트다운==1이면 패배). 타이머 길이 후보 181초(트리거 `Countdown = 181`) [추정].

## 9. 해독 못한 부분과 이유

1. **트리거 난독화**: 조건/액션 슬롯 사이에 무효 타입(23/59 초과) 쓰레기 값을 넣어 두었고(엔진은 무시), 플레이어/로케이션/유닛 필드에 무작위 값이 들어간 가짜 트리거가 대량. Deaths 조건은 EUD 주소 비교로 위장.
2. **로케이션(MRGN) 파괴**: 255개 항목 전부 난수 -> 스폰/이동 경로 좌표 복원 불가. 스폰 지점은 번호(15/23/31/39, 68/70/72/74 등)로만 앎.
3. **STRx 12.7MB 페이로드**: 문자열 51KB 뒤에 약 780KB 비영 데이터(EUD 로더가 런타임 복사하는 트리거/데이터로 추정). 뽑기·합성·웨이브 반복 로직이 여기 있는 것으로 보이나 미해독 (이 페이로드가 TRIG에서 참조되지 않는 당첨 메시지 문자열의 소비처).
4. 라운드별 몬스터 마리수·스폰 간격·이동 경로·타이머 길이(보스 제한시간 포함)는 위 이유로 미확정. 재구현 시에는 원작 체감에 맞춰 직접 튜닝 필요.
5. 유닛 사거리/공속/실제 데미지: CHK에 정보 없음 (스타 기본값 사용 가정).
