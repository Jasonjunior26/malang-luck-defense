# 카카오 로그인 설정 (Supabase Auth + Kakao)

코드는 준비돼 있고 `config.js` 의 `KAKAO_ENABLED:false` 라서 버튼이 "준비 중"(타이틀 프로필)으로만 보인다. 아래를 끝낸 뒤 true 로 바꾼다.

## 1. 카카오 개발자 앱
1. https://developers.kakao.com > 내 애플리케이션 > 애플리케이션 추가 (앱 이름: 말랑 디펜스).
2. 앱 설정 > 플랫폼 > Web 에 게임 도메인 추가 (예: `https://사용자명.github.io`).
3. 제품 설정 > 카카오 로그인 > **활성화 설정 ON**.
4. 같은 화면 **Redirect URI** 에 `https://oktgigevvwlczqavbyuq.supabase.co/auth/v1/callback` 등록.
5. 동의항목: **닉네임, 프로필 사진만** 설정(필수/선택 동의). 이메일은 받지 않는다 (비즈 앱 불필요).
6. 보안 > **Client Secret** 생성, 활성화 ON. 앱 키 > **REST API 키**를 복사.

## 2. Supabase
1. Authentication > Providers > **Kakao** 활성화. Client ID = REST API 키, Client Secret = 위 Client Secret.
   - 이메일 항목을 안 받으므로 "Allow users without an email" 을 켠다(Supabase 설정에 있을 때).
2. Authentication > URL Configuration > **Site URL** = 게임 주소, **Redirect URLs** 에 게임 주소(`https://사용자명.github.io/저장소/` 와 로컬 테스트 주소)를 추가.
3. 마이그레이션 적용: SQL Editor 에서 `supabase/migrations/003_accounts.sql` 실행.
4. 함수 배포: `supabase functions deploy submit-score --no-verify-jwt` (함수는 `/auth/v1/user` 로 JWT 를 검증한다. 추가 시크릿 불필요: SUPABASE_URL/ANON_KEY 는 자동 주입).

## 3. 활성화
- `config.js` 의 `KAKAO_ENABLED: true` 로 변경 후 배포 (sw.js `CACHE_VERSION` 올리기).
- 확인: 프로필 > "카카오로 계정 연결" > 카카오 동의 > 복귀 후 "기록을 계정에 연결할까요?" 모달 > 연결 > 프로필에 "카카오 연결됨".
- 다른 기기/브라우저에서 같은 카카오로 로그인하면 연결된 닉네임·기록을 불러온다(기기 로컬 기록은 합치지 않음).

## 동작 메모
- 로그인은 선택. 안 해도 모든 기능 동작. 세션은 localStorage `malang-auth`, 만료 60초 전 자동 갱신.
- 하나의 카카오 계정에는 player 하나만 연결된다. 이미 다른 계정에 연결된 기기 기록은 연결할 수 없다.
