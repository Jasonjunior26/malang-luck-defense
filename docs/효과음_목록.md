## BGM (곡 3개, ui.js `BGM` 표 192줄~)
- **곡 데이터**: `BGM.title`(C장조 AABA 8마디, bpm 112, 스윙 .14), `BGM.play[0..2]`(일반곡 3변주 8마디: 0 C장조 C-G-Am-F bpm 100 / 1 G장조 G-Em-C-D bpm 104 / 2 A마이너 팝 Am-F-C-G bpm 98), `BGM.boss`(Am-F-Dm-E, bpm 132, 둥근 사각파 lp 1500). 챕터 id 로 변주 선택 `(id-1)%3` (`_bgVariant`). 엔딩 `BGM_END.over/win`(시작초, MIDI, 길이, 파형, 볼륨 목록).
- **곡 표 필드**: `chords`(마디별 [근음 MIDI, "M"/"m"]), `mel`(마디당 16칸, 글자=펜타 인덱스, `.`쉼 `-`이어짐), `scale`/`base`, `bass`(r f o) `arp`(0~3) `kick` `snare` `hat` 16칸 패턴, `bpm` `swing` `vm`(멜로디) `vb`(베이스) `vp`(패드) `va`(아르페지오) 볼륨. 작성법 주석은 ui.js 184~191줄.
- **템포/강도**: 일반곡 bpm = 곡 bpm + 라운드*0.5(최대 AUD.bpmRoundMax 24) + 몹 비율*AUD.bpmDangerMax(14). 강화 레벨 0 멜로디+베이스 / 1 +패드+하이햇(라운드 5 또는 몹 25%) / 2 +킥·스네어·아르페지오(라운드 15 또는 몹 50%). 타이틀·보스는 항상 레벨 2. `AUD.bpmBase` 는 전체 보정(기본 0).
- **전환**: 화면/라운드로 곡 키(title, play0~2, boss) 결정 -> 곡별 버스를 1초(`BGM_XFADE`) 크로스페이드. 타이틀 화면 첫 터치 후 타이틀 곡, 게임 시작 시 일반곡, 보스 라운드는 보스곡. 게임오버/승리(S.over, S.win)는 곡 1초 페이드아웃 후 효과음(over/win) 뒤 1.3초에 엔딩 스팅어 1회.
- **공간감**: 곡 버스 -> BB 와 점8분음표 피드백 딜레이(`_bgFx`, fb .3, 센드 .28) , 음별 StereoPanner(멜로디 +.2, 종소리 +.35, 아르페지오 -.3, 패드 +-.25, 하이햇 +-.3). 스윙은 홀수 16분음표를 `swing` 만큼 뒤로 밈.
- lookahead 스케줄러(`_bgTick`, 90ms 주기, 0.3초 선행), 이벤트 생성은 순수 함수 `_bgEv`(오프라인 렌더가 같은 함수 사용). 모달 열림 시 BB 45%, 탭 백그라운드 시 AudioContext suspend, 복귀 시 resume. 소리 모드가 BGM 끔이면 버스 무음.
- 오프라인 확인: 스크래치패드 `renderBgm.js` -> bgm_title/play/play_g/play_am/play_lvl0/boss.wav (30초, 피크 약 0.08 출력레벨, 클리핑 0).

## 소리 버튼(#snd)
탭마다 순환: 🔊 효과음+BGM -> 🔉 효과음만 -> 🔇 끔. localStorage `malang-snd`(0/1/2), 구 키 `malang-mute` 도 함께 기록. 변수 `MUTED`(끔일 때 true), `SND_MODE` 유지.

## 믹싱
sfxBus/bgmBus -> master Gain(0.9) -> DynamicsCompressor(-16dB, 6:1) -> destination. 효과음 동시 발음 상한 14(`AUD.maxVoices`).
